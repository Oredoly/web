# 后端负责人展示脚本

适用环节：第一次正式组会 11:18-11:43，共 25 分钟

目标：让全组 0 基础成员看懂“我们要做的网站长什么样、代码怎么跑、怎么协作、AI 怎么辅助”，不是教完语法。

## 展示总原则

- 每个概念对应一个屏幕演示。
- 只讲“这一步是什么、下一步去哪”，不逐行讲代码。
- 25 分钟内不追求讲完，追求大家记住 3 件事：
  1. 项目怎么启动
  2. Git 提交流程怎么走
  3. 遇到问题怎么用 AI 辅助

## 1. 跑起现有系统（1 分钟）

屏幕操作：

1. 打开 `C:\Users\nmg2333\Desktop\project\backend`
2. 终端执行 `node app.js`
3. 浏览器打开 `http://localhost:3000/auth/login`

说：

> 这就是我们后面要维护的系统。今天先不用看懂所有代码，只要知道它能跑起来。

## 2. Git/GitHub 演示（7 分钟）

屏幕操作：

1. 打开 GitHub 仓库页面，说“这里保存所有人的代码和历史”。
2. 打开本地项目文件夹，说“这是本地代码，Git 用来同步两者”。
3. 现场执行：

```bash
git clone <仓库地址>
git status
git add .
git commit -m "负责人演示"
git push
```

4. 演示分支和合并请求：

```bash
git switch -c demo/负责人演示
```

修改 README 后提交推送，打开一个合并请求。

说：

> 今天你们只需要做一件事：把自己的名字加进成员列表，提交并发起合并请求。

## 3. Node.js + Express 演示（6 分钟）

屏幕操作：

1. 打开 `app.js`，找到：

```js
app.use('/auth', require('./routes/auth'));
```

2. 打开 `routes/auth.js`，找到登录路由。
3. 打开 `controllers/authController.js`，找到登录页的控制器。
4. 浏览器打开登录页，指着页面说“这里就是最后生成的结果”。

讲清楚一条链路：

```text
浏览器请求 /auth/login
  -> Express 路由 routes/auth.js
  -> 控制器 controllers/authController.js
  -> EJS 页面 views/auth/login.ejs
  -> 返回浏览器
```

不要讲 Express 的全部语法，只讲“路由负责接请求，控制器负责处理，页面负责显示”。

## 4. SQLite 演示（5 分钟）

屏幕操作：

1. 打开 `database/pbl_platform.db`，说“数据库就是一个文件”。
2. 打开 `database/schema.sql`，指出主要表：用户、学校、班级、课程、作品、成长档案。
3. 可以用终端跑一条查询，展示数据确实存在：

```bash
node -e "const Database=require('better-sqlite3'); const db=new Database('database/pbl_platform.db'); console.log(db.prepare('SELECT username, real_name, role FROM users LIMIT 5').all());"
```

说：

> 暂时用 SQLite，是因为不需要安装数据库服务器，一个文件就能保存所有数据，适合我们 0 基础起步。

## 5. AI/agent 使用演示（6 分钟）

屏幕操作：

1. 打开一个 AI 工具。
2. 现场输入一个适合零基础的问题：

```text
我是零基础，请用 Node.js + Express 写一个最简单的接口，
返回 { "message": "hello" }，并逐行解释。
```

3. 把生成的代码放进项目运行，证明 AI 结果可以跑。
4. 再对比一个坏提问：

```text
坏提问：帮我写一个网站
好提问：请解释 app.get('/hello', (req, res) => res.send('hello')) 是什么意思
```

说：

> AI 可以帮你解释代码、生成小功能，但你不能直接照抄，必须能讲清楚它为什么这么写。

安全提醒：

- 不把 `.env`、密码、`SESSION_SECRET`、数据库内容发给 AI。
- AI 生成代码后要人工检查。
- 核心代码必须自己理解后再提交。

## 结束动作（最后 1 分钟）

让大家记住三句话：

1. 项目启动命令是 `node app.js`。
2. 代码协作流程是 `clone -> add -> commit -> push -> 合并请求`。
3. 遇到看不懂的代码，可以问 AI，但必须把解释写下来。

当场布置：

> 会后每人用 AI 解释 `app.js` 里的任意一行代码，写一段 100 字说明，发到群里。
