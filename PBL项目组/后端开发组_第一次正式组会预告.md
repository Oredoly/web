# 后端开发组第一次正式组会预告

时间：明天（8月7日）10:00-12:00

地点：待定

参会：后端开发组全体成员、指导老师

形式：线下 + 共享屏幕

## 议程

1. 开发组调研成果展示，每人 8 分钟，可本地演示
2. 顾问组问卷结果简略展示，2 分钟
3. Brainstorm 我们需要搭建的网站功能，初步划分需求优先级和工作模块
4. 根据工作模块初步人员分工
5. 负责人简略介绍 Git/GitHub、Node.js + Express、SQLite、AI/agent 使用
6. 老师补充
7. 交流答疑

## 会前准备

- 开发组：每人准备 调研报告，准备 8 分钟展示，讲清“它是什么、核心功能、我们能学什么、第一版不做”。
- 顾问组：两位同学准备问卷结果展示；两位同学准备 Brainstorm 引导；两位同学负责现场记录整理。
- 全体：提前安装 Node.js LTS、VS Code、Git，注册 GitHub 账号；没有装完的也可以在会中记录问题。
- 负责人：准备 Git 演示仓库、后端项目运行演示、共享屏幕安排。

## 会后交付

- P0/P1/P2 需求池
- 工作模块和人员分工
- 本周任务表
- 第一次 Git 练习：每人把名字加入成员列表并提交
